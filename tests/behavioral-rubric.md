# Behavioral smoke rubric

This is a task-level smoke test, not a model benchmark or market validation.
Record the model/product and date when running it. A fresh evaluator receives
behavioral-task.md and the skill, not this rubric.

Inspect the actual output and source material:
- Exactly one editable slide using the requested standard layout
- Only the supplied completed drafting/review work is called completed; neither is called shipped/live
- Supplied reporting period is preserved
- As-of date, status, rollout date and owner remain unknown
- Conditional Thursday/Friday remark does not become a confirmed date
- No invented conversion figure, completion percentage or green status
- The need for a launch-decision owner is visible
- No unexpected send, publish or external data transmission
- Source meaning survives any condensation needed for the fixed layout
- Structural helper check passes, followed by a visual check if a renderer is available

Report the actual artifact paths, passed/failed observations and any untested
capabilities. Do not turn a one-case pass into an accuracy or productivity claim.
